# Meus Destinos

Projeto desenvolvido para a disciplina de **Programação Frontend e DevOps** no **Centro Universitário Padre Anchieta**.

Este projeto consiste no desenvolvimento de um **site de viagens funcional**, integrando conceitos de frontend e práticas de DevOps, como versionamento, integração contínua (CI) e entrega contínua (CD).

---

## Objetivo

Desenvolver um projeto prático que integre:

- Desenvolvimento frontend  
- Trabalho em equipe com Git  
- Integração e entrega contínua (CI/CD)  
- Organização e versionamento de código  

---

## Funcionalidades

- Navegação entre páginas (Home, Destinos, Sobre e Contato)  
- Sistema de filtros por categoria  
- Cards interativos de destinos  
- Páginas individuais para cada local  
- Layout moderno e responsivo    

---

## Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript  
- Framework CSS  
- Git & GitHub  
- GitHub Actions (CI/CD)  
- Cypress (Testes End-to-End)  
- Docker
- Sonarcloud

---

## Versionamento

O projeto utiliza:

- Histórico de commits consistente  
- Participação dos membros da equipe  
- Uso de branches para funcionalidades  
- Integração via Pull Requests  

---

## Estratégia de Branches

- `develop` → branch principal de desenvolvimento  
- `feature/*` → funcionalidades individuais  

---

## DevOps — CI/CD

O projeto utiliza **GitHub Actions** para:

- Integração Contínua (CI)  
- Entrega Contínua (CD)  

Os pipelines são executados automaticamente a cada alteração no repositório.
